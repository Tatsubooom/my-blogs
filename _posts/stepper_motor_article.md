## 実際に作ってみよう

### 第一章 準備編

とりあえず、まずは先行研究探しから。適当に「ステッピングモーター 演奏」とかてググって出てきたものを親だと思って作業を始める。一番初めに出てきたこの記事に決定。細かいとこは後にして、最低限必要なものをかき集めます。全部アリエクで買ったよ。

#### 使うもの

**① ステッピングモーター × 欲しいだけ**

これが無くてどうする？？？駆動方式は**バイポーラ**駆動。安いからって、間違えても二線のユニポーラモーターとか買わない。後述のライブラリ関係で「NEMA17」シリーズを推奨。A4988 が最大 2A 出力だからモーターもそれ以下にしようね。今回は定格 1.7A。

**② 制御モジュール「A4988」 × 欲しいだけ（モーターと同量）**

ややこしいステッピングモーターの制御を二本の信号線だけでやってくれるスゴイ奴。最低、モーターの数分は買おう。結構ぶっ壊しやすいから、二台くらい多めに買っとくといいかも（1 敗）。

**③ Arduino UNO × 1（モーター数で増減）**

本システムのマイコン部分。先人になぞらえて Arduino だけど、頑張ればラズパイでも行ける。

**④ モーター用電源（12〜24V くらい）**

A4988 を通してモーターに電源供給する。AC コンバーター（PC 充電器みたいなやつ）とかスイッチング電源とかいろいろあるよ。今回は前者で、12V / 10A。電圧は値段と相談。アンペアはモーターによるとしか言えんが、モーターの定格電流 × 個数分は最低限用意しよう。

**⑤ 配線・雑品**

ブレットボード、ジャンパ線、ジャンパピン…こんなん、なんぼあってもいいですからね。テスターとか電圧/電流計があるとテストや不具合箇所発見しやすくてうれしい。Arduino を使っているなら **"CNC シールド"** って追加パーツがあるからそれ使うと七面倒な配線作業をスキップできる。

### 第二章 設計・組み立て編

CNC シールドがあると組み立ては超簡単。Arduino にシールドを上からブッピガンして、その上からさらに A4988 ドライバーをガショガショはめていく。1A を超える電流をモーターに流すなら、A4988 にヒートシンクもついでに付けようね。（付けてもクソ熱い）

![部品三種盛](/assets/blog/stepper_motor/pdf1_p3_assembly_before.jpg)

![合体後](/assets/blog/stepper_motor/pdf1_p3_assembly_after.jpg)

シールド内のジャンパピンはマイクロステップの設定で、三つ横に並んだ上下組のピンが A4988 における MS1, MS2, MS3 に接続されている。設定方法はこちら。

@[card](https://www.originalmind.co.jp/YOUR_LINK_HERE)
<!-- ↑ 【URL差し替え】※3 株式会社オリジナルマインド Web「Arduino でメカトロニクス製品を動かそう」 -->

:::message alert
分解数が上がるにつれて純粋な回転量が下がるので、**回転しているときの見た目がしょぼくなること**・回転が滑らかになるので**音量が下がること**に注意。好みを探そう。
:::

次に、A4988 の電流調整をする。A4988 のセンス抵抗 Rs とモーターの定格電流を確認。

![A4988アップ](/assets/blog/stepper_motor/pdf1_p3_a4988_closeup.jpg)

制限電流は以下の式から求められる：

```
I_limit = V_ref / (8 × Rs)
```

テスターなどで V_ref（可変抵抗 to GND）を測りながら、モーターの定格電流と合わせていく。最終的に、モーターの数分調整すればそれで OK。

:::message alert
A4988 の横にあるピンへのモーター接続は、データシートを確認して正しい場所に繋ごう。**接続がぐちゃぐちゃだとうまく動かないぞ！**
:::

ついでに、音響場所として適当な段ボールの箱に固定する。本当はプラやアルミの箱がいいのだけど…冬コミまでに準備間に合わねぇですわよ。

### 第三章 ソフトウェア準備編

ここまでで、ハードウェア面はほぼ完成。次にソフトウェア面を作っていく。一から作るのはちと厳しいので、マイコンを動かす用のソフトウェアも先人から受け継ぐ。Arduino に焼くプログラムは **「Arduino-MIDI-Stepper-Motor-Instrument」**。ArduinoIDE から書き込みを行う。

@[card](https://github.com/jzkmath/Arduino-MIDI-Stepper-Motor-Instrument)

MIDI（音源ファイル）の送受信には、**Domino** と **Hairless-midiserial**、**loopMIDI** を使うよ。順番にインスコしておこう。

#### セットアップ手順

1. **LoopMIDI** を立ち上げ、左下の＋ボタンからポートを一つ作る。

![LoopMIDI設定画面](/assets/blog/stepper_motor/pdf1_p4_sw_loopmidi.jpg)

2. **Hairless MIDI** の設定：MIDI IN をさっき作成したポートに、Serial Port には Arduino の Serial を Arduino IDE で確認して設定。

![Hairless MIDI設定画面](/assets/blog/stepper_motor/pdf1_p4_sw_hairless_midi.png)

:::message alert
**プログラムの書き込みをするときには、必ず Hairless-midiserial の「Serial<->MIDI Bridge On」を切ろう。** 切り忘れると、書き込めないのにエラーが出ないから面倒なことになる…。
:::

3. **Domino** の環境設定から MIDI-OUT を選択。ポート A の MIDIOUT デバイスに LoopMIDI で作成したポートを設定。音源ファイルはお好きにどうぞ。

![Domino環境設定画面](/assets/blog/stepper_motor/pdf1_p4_sw_domino_config.jpg)

#### 接続フロー

```
Domino
  │ (Port-IN)
  ▼
Loopmidi
  │ (MIDI-IN / Port-OUT)
  ▼
Hairless-midiserial
  │ (Serial-port)
  ▼
Arduino-serial
```

:::message
loopmidi を**最初に**起動しておこう（バグ防止）。好きな MIDI ファイルを流す前に、※4 の作者が用意しているテスト用 MIDI ファイルで必ずテストしよう。ライブラリに同梱されているよ。
:::

### +α ラズパイで Arduino のシリアル通信を盗んで表示する

完成写真の左にあるちっちゃいディスプレイ。これ、Arduino へのシリアル通信をラズパイで盗んで再生している音源データを表示しています。ArduinoIDE を使ってコンパイルすることで、ライブラリを使いまわせば割とソフト面は簡単にできちゃうのだ。

ただし、Arduino は **5V 駆動** なのに対して、ラズパイは **3.3V 駆動** だから何らかの方法でラズパイに入力される信号の分圧が必要になる。今回はお試しだから抵抗器三本使って 5V を 2/3 に分圧している。Arduino の RX は GP1 に、お互いの GND を接続する。

![ラズパイPico配線](/assets/blog/stepper_motor/pdf1_p6_raspi_pico_wiring.jpg)

あとは適当なモニター買って繋げるだけ。モニター 1 つの時のテストプログラムはこちらから。

@[card](https://github.com/YOUR_ACCOUNT/Arduino-Serial-Sniffer-by_Raspberry-PI-Pico)
